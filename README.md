# Caça-Fantasma Curitiba • 2026

Landing page temática inspirada em Caça-Fantasmas (Ghostbusters), com visual retrô e efeitos interativos.

## Tecnologias

- HTML5
- CSS3 (fontes Creepster e VT323)
- JavaScript (partículas e fantasmas que seguem o mouse)

## Estrutura

```
├── index.html   # Página principal
├── style.css    # Estilos e animações
└── script.js    # Efeitos de partículas e cursores fantasma
```

## Como visualizar

Abra o `index.html` no navegador ou sirva localmente:

```bash
python3 -m http.server 8000
# http://localhost:8000
```
